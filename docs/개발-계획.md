추측이 아니라 파일을 열어 센 값이다.

| 항목 | 실측 |
| --- | --- |
| 미션 | **66개** (6코스 × 11) · 11번이 코스 회고(`isFinale`) |
| 인증 종류 | **전부 `photo`** — 영상·음성·그림 경로는 명세만 있고 데이터에 없다 |
| 프로토타입 | 1파일 **5,653줄** (템플릿 2,198 / 로직 3,455) · 화면 23개 · `sc-if` 분기 29개 |

## 1. 문서끼리 어긋나는 것 7건

`상세 기획서`·`화면 정책.md`·`economy.json`·`missions.json` 이 서로 다르게 적은 값이다.
**기획서가 "동작하는 화면 자체가 명세다"라고 적었으므로 프로토타입을 기준으로 삼되**, 아래는 합의가 필요하다.

| # | 항목 | 기획서 | 화면 정책 | 데이터 | 제안 |
| --- | --- | --- | --- | --- | --- |
| 1 | 코스당 미션 수 | 30개 | — | **11개** | 데이터대로 **11개**. 기획서의 30일은 확장판 |
| 2 | 회고 턴 수 | LLM 3~8 | 소요시간 규칙 2~5 | — | **LLM 3~8** (프로토타입 `planTurns` 가 그렇다) |
| 3 | 대화 연장 | 💎10 · 5분 | 💎8 · 3턴 | 💎10 · 5분 | **💎10 · 5분** |
| 4 | 사진 용량 | 120MB | 12MB | — | **12MB** (전부 사진이라 120MB는 과하다) |
| 5 | 구독권 선물가 | 6,900원 | 9,900원 | 6,900원 | **6,900원** |
| 6 | 랭킹 순위 | LV → XP | LV → XP | **XP → streak** | **LV → XP** (economy.json 을 고친다) |
| 7 | 게스트 모드 | 없음 | "계정 없이 둘러보기" 있음 | — | **넣는다** — 심사위원이 로그인 없이 바로 본다 |

⚠️ **6번은 데이터 파일이 틀린 쪽이다.** 코드가 `economy.json` 을 읽으면 조용히 잘못된 랭킹이 나온다.

## 2. 기술 결정

newb 방식 그대로 간다.

| 영역 | 선택 | 비고 |
| --- | --- | --- |
| 프론트 | Next.js (App Router) + TypeScript | |
| 상태 | **React 기본만** (useState/useContext) | 외부 상태 라이브러리 금지 — newb 규칙 |
| DB·인증 | Supabase (Postgres + Google OAuth + RLS + Storage) | |
| 배포 | Vercel | `main` push = 자동 배포 |
| LLM | **Gemini** (`@google/genai`) | 아래 ⚠️ |
| 결제 | **붙이지 않는다.** 목업 유지 | 확인창 → 로딩 1.5초 → 완료 토스트 3단계 UI는 그대로 산다 |
| 이메일 | **보류** (도메인 없음) | 파트너 초대·선물은 화면까지만 |

### ⚠️ 판단이 필요한 것 — 스타일을 어떻게 옮기나

프로토타입은 DC 템플릿이라 **스타일이 전부 인라인**이다(CSS 클래스가 없다).
Tailwind 유틸로 다시 쓰면 5,653줄을 전부 번역하는 일이고, 옮기다 틀어져도 대조할 기준이 프로토타입 화면뿐이다.

**제안: 인라인 스타일을 그대로 가져온다.** Tailwind 는 newb 와 같은 스택을 유지하려고 설치만 하고 화면 코드에는 쓰지 않는다.
`globals.css` 에는 `@font-face` · 키프레임 6종(`plSlideL` 등) · hover 규칙만 둔다(인라인으로는 `:hover` 와 미디어쿼리를 못 쓴다).
반응형은 프로토타입이 이미 쓰는 방식 그대로 — `narrow` 상태를 재서 값을 가른다.

### ⚠️ LLM 비용표는 다시 계산해야 한다

`LLM 비용.md` 의 권고(**질문 Haiku · 채점 Sonnet**, 월 490원)는 **Claude 단가 기준**이다.
Gemini 로 가면 그 표는 그대로 못 쓴다. 2단계에서 실제 호출 토큰을 재서 다시 적는다.

## 3. 단계

**링크가 먼저 산다.** 매 단계 끝에 `main` push = 배포. 단계마다 배포된 링크가 조금씩 자란다.

### 0단계 — 링크 살리기 ⏱ 약 1시간

아무것도 없어도 주소가 먼저 있어야 한다.

- Next.js 스캐폴드 + GitHub private repo + Vercel 연결
- 로고 한 장짜리 페이지 배포 → **공개 URL 확보**
- env 자리만 미리 등록(`GEMINI_API_KEY`·Supabase 3종) — 나중에 넣으면 빌드가 그때 처음 깨진다
- 도메인 없으므로 `*.vercel.app`. 이름은 남는 것으로 잡는다

**끝나는 조건:** 주소를 눌러 PLOVE 로고가 뜬다.

### 1단계 — 화면 이식 ⏱ 가장 크다 (전체의 60%)

**1-0 에셋 먼저** — 32MB 를 그대로 올리면 첫날부터 느리다. 표시 크기의 2배로 줄이고 WebP 로. (포트폴리오에서 760MB 디코딩으로 탭이 죽은 적이 있다)

| 묶음 | 화면 | 끝나면 |
| --- | --- | --- |
| **1-A 진입** | start · signin · policy · terms · pick · greet(5단계) · family · petSetup | 게스트로 과목 골라 온보딩까지 |
| **1-B 홈** | home(미션 경로·노드 상태 4종) · 미션 미리보기 | 66개 미션이 경로로 보인다 |
| **1-C 핵심 루프** | run · chat · mresult · streakPop | **한 판이 끝까지 돈다** (NPC 말은 아직 가짜) |
| **1-D 테스트** | countdown · quiz(15문항) · result | 온보딩에서 "내 레벨 찾기"가 열린다 |
| **1-E 부가** | store · profile · streak · rank · finale | 전 화면 완성 |

저장은 이 단계에서 **localStorage** 로 한다(프로토타입과 동일). 3단계에서 Supabase 로 갈아끼운다.

**끝나는 조건:** 배포된 링크에서 로그인 없이 미션 한 판을 끝까지 돌 수 있다.

### 2단계 — Gemini ⏱ 전체의 15%

**저장보다 먼저 한다.** 1-C 까지 끝나도 NPC 가 말을 못 하면 데모가 안 된다. 계정은 없어도 한 판은 돌지만, 대화가 없으면 이 서비스가 아니다.
(기획서 19장은 OAuth·스토리지를 1차로 두었다. 해커톤 데모라는 조건에서 순서를 뒤집는 것이고, 그 이유를 여기 적어 둔다.)

- 호출 5곳을 **서버 라우트로만** 보낸다 — 키가 브라우저에 나가면 안 된다
- 프롬프트는 기획서 12장 문면 그대로. 모델만 Gemini
- 실패 처리: 대화 실패 → "다시 물어보기" · 채점 실패 → 사전 점수로 진행
- **이밸 이식** (`PLOVE 이밸.dc.html`) — 28회 실행, `heavy` 케이스는 통과해야 배포
- 실제 토큰을 재서 비용표를 Gemini 기준으로 다시 쓴다

**끝나는 조건:** 링크에서 NPC 와 진짜 대화가 되고 채점 코멘트가 나온다.

### 3단계 — Supabase ⏱ 전체의 20%

- Google OAuth (게스트 모드는 남긴다)
- 스키마 — 기획서 14장에서 **범위 밖 테이블을 뺀 축소판**(`payments`·`gifts`·`partners`·`shares` 제외)
- 진행 상태 저장·복원 · `day_marks` 출석 · `records`·`record_slots`
- Storage 에 인증 사진 (지금은 `URL.createObjectURL` 이라 새로고침하면 사라진다)
- 스트릭은 **파생값**이다 — `day_marks` 에서 재계산한다

**끝나는 조건:** 로그인하고 껐다 켜도 진행이 남아 있다.

### 4단계 — 마감 ⏱ 전체의 5%

- 모바일(760px 분기) 전 화면 확인
- 예외·빈 상태 7종 (기획서 17장)
- OG 태그·썸네일(`og-thumbnail.png` 있다)
- 효과음 7종 (Web Audio 합성, 음원 파일 없음)

## 4. 이번에 안 하는 것

빼는 이유를 적어 둔다 — 다음 사람이 누락으로 보고 다시 만들지 않게.

| 항목 | 왜 |
| --- | --- |
| 실제 결제 (PG) | 지시 — 목업 유지. 화면과 3단계 흐름은 그대로 산다 |
| 이메일 발송 | 도메인이 없다. SPF·DKIM 없이 보내면 Gmail 이 스팸으로 분류해 초대가 전달되지 않는다 |
| 파트너 연결 | 초대가 메일이라 위와 함께 묶인다. 화면은 1-E 에서 목업으로 산다 |
| Vision 사진 판정 | `analyzePhotos()` 자리는 두고 파일 유무·메모만 본다 (프로토타입과 동일) |
| 회고 공유 링크 | 서버 공유 페이지가 필요하다 |
| 팀 구독 어드민 | 문의 팝업까지만 |
| 영상·음성·그림 인증 | **데이터에 없다.** 66개 전부 사진이다 |
