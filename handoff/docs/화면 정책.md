## 화면 목록과 정책

### 01 시작 (`start`)
- 빨간 전면. 로고 + "사랑, 연습하러 가볼까요?" + 시작하기
- **나감**: 시작하기 → 로그인(미로그인) 또는 과목 선택(로그인됨)

### 02 로그인 (`signin`)
- Google로 계속하기 / 계정 없이 둘러보기 / 약관 동의 체크
- **버튼 활성**: 약관 동의 전에는 두 버튼 모두 비활성 (누르면 "약관에 동의해야 시작할 수 있어요")
- **게스트**: 기록이 브라우저에만 남는다고 명시
- **연결 지점**: `googleSignIn` — 실제 OAuth 호출 후 서버 진행 상태를 복원

### 03 처리방침 (`policy`)
- 무엇을 모으나요 / 어디에 쓰나요 / 보관 기간 / 공유 / 민감한 기록 / 권리 / 문의
- **진입**: 로그인 화면의 "전문 보기", 프로필 → 개인정보 처리방침
- **나감**: ← 는 들어온 화면으로 돌아간다

### 04 과목 선택 (`pick`)
- 빨간 전면. 6과목 3×2 그리드, 누적 학습자 수 표시
- **버튼 활성**: 과목을 고르기 전 계속하기 비활성
- **나감**: 가족 → 가족 구성 / 반려동물 → 반려동물 설정 / 그 외 → 인사

### 05 온보딩 (`greet`, 5단계)
1. 인사 — 👋 눌러야 다음으로
2. 이름 — 빈칸이면 다음 비활성. Enter로 진행
3. 사랑 질문 — 4선택지, 진입 시 1번 선택됨. ↑↓로 이동
4. 반응 — 선택지 없음. Enter로 진행
5. 시작 지점 — 기초부터 / 내 레벨 찾기
- **가족·반려동물**: 4단계 뒤에 설정 화면이 끼어든다
- **뒤로**: 1단계에서 뒤로 = 과목 선택

### 06 가족 구성 (`family`)
- 누구와 함께 사는지 복수 선택 (부모·형제·자녀·조부모·배우자 등)
- **버튼 활성**: 하나도 안 고르면 다음 비활성
- **정책**: 고르지 않은 가족을 전제로 한 미션은 생성하지 않는다. 미션 문구의 `{m}`이 고른 가족으로 치환된다

### 07 반려동물 설정 (`petSetup`)
- 종류 복수 선택 + 종류별 이름 입력(선택)
- **버튼 활성**: 종류 미선택 시 다음 비활성
- **정책**: 이름을 넣으면 미션에서 이름으로 부른다(`{p}`). 산책을 전제하지 않는다

### 08 시작 지점 (`testIntro` / 온보딩 5단계)
- "처음 듣는 ○○이네요, 뭐부터 시작할까요?"
- 기초부터 → 1번만 열린 홈 / 내 레벨 찾기 → 카운트다운

### 09 카운트다운 (`countdown`)
- 3 → 2 → 1. 취소 불가

### 10 레벨 테스트 (`quiz`, 15문항)
- 1~14번 5초, 15번 30초. 남은 초 · N/15 · 단계 · 진행 바
- **시간 초과**: 자동 제출
- **정책**: **테스트는 1회만.** 결과 화면에 다시 하기 없음. 최고 LV.3

### 11 테스트 결과 (`result`)
- 시작 레벨 / 획득 경험치 / 획득 보석 3칸. 채점표(좌하) · 학습 시작
- **LLM 실패**: 규칙 기반 대체 문구

### 12 채점표 (모달)
- 캐릭터가 본 당신(감성 해석) + 문항별 응답
- **닫힘**: 배경 클릭 또는 ✕. 내부 클릭으로는 닫히지 않는다

### 13 홈 (`home`)
- 사이드바(클래스 6 + 스토어·프로필·랭킹) · 코스 헤더 · 🔥💎 스트릭 · 미션 경로
- **미션 노드**: 완료 녹색+✓ / 진행 가능 빨강 / 잠김 회색+🔒
- **복귀 배너**: 2일 이상 쉬었으면 캐릭터가 먼저 말 건다
- **스트릭 끊김**: 배지가 "오늘부터 다시"로 (비난 없음)
- **코스 완료**: 녹색 카드 + 다음 코스 추천

### 14 미션 미리보기 (노드 클릭)
- 단계·번호 · 제목 · 🔥+XP · 💎+보석 · ⏱소요 · 시작 버튼
- **버튼 문구**: 잠김 "이전 미션을 완료해야 열려요" / 오늘 소진 "미리 시작" + 💎20 + 남은 시간 / 완료 "다시 하기" + 💎10 / 30번 "회고 열어보기"
- **닫힘**: 바깥 클릭
- **보석 확인창**: 남은 시간 칩 · 미션 제목 · "보석을 사용해서 지금 시작하시겠어요?" · 취소/보석 N개. 부족하면 스토어로(필요·보유·부족 표시). 다시 하기 아이템이 있으면 "아이템 사용"

### 15 미션 수행 (`run`)
- 좌상단 캐릭터 + 말풍선(과제) · 사진 슬롯 + 번호 매긴 기록 칸 · 하단 좌측 "과목 · 미션 N · 제목" + 안내
- **버튼 활성**: 사진과 기록이 다 차야 다음 활성
- **임시 저장**: 입력할 때마다 로컬 저장. 재진입 시 "쓰던 기록이 남아 있어 그대로 불러왔어요" + 이어쓰기/새로쓰기
- **사진 실패**: 이미지 아님 / 12MB 초과 / 로드 실패 → 빨간 배너 + 닫기

### 16 회고 대화 (`chat`)
- 상단 캐릭터 + 미션 제목 + 턴 표시(N/M)
- **턴 수**: 소요 5분 이하 2턴 / 10분 이하 3턴 / 20분 이하 4턴 / 그 이상 5턴
- **LLM 실패**: "잠깐 말이 끊겼어요" + 다시 물어보기 버튼
- **턴 소진 후**: 💎8로 3턴 더 (보석 있을 때만 노출)
- **마무리**: 내 답변 2개 이상부터 활성

### 17 미션 결과 (`mresult`)
- 캐릭터 축하 모션 · 획득 경험치 · 보석 · 캐릭터 코멘트
- **판정**: 사진 적합성 40 + 기록 구체성 30 + 대화 깊이 30 → LLM 종합 점수
- **XP 배율**: 95점↑ 1.4배 / 80점↑ 1.2배 / 그 외 1.0배. 보석 +2 (95점↑ +1)
- **LLM 실패**: 대체 코멘트 + "평가를 다시 받아보기"
- **Vision 연동 지점**: `analyzePhotos()` — 현재는 사진 유무·메모만 본다

### 18 코스 회고 (`finale`, 30번)
- 블로그 형태로 29개 미션의 사진·기록·대화·캐릭터 한 마디를 시간순 · 합계(경험치·보석·사진·글자) · 캐릭터 편지 · 공유
- **보상**: 500 XP + 보석 32~33
- **기록 없음**: "아직 기록이 없어요. 미션을 하나씩 해보면 이 자리에 사진과 내 말이 쌓여요."
- **공유 정책**: 기본 "링크 아는 사람". 전체 공개 / 링크 / 비공개 중 선택. 사진 제외 토글. 만료 7일·30일·없음. 비공개면 링크가 만들어지지 않는다

### 19 스토어 (`store`)
- Plus 월 9,900원 (7일 무료 없음) · 보석 아이템 · 보석 충전 · 함께·선물
- **아이템**: 오늘 미션 하나 더 20 / 스트릭 지키기 15 / 미션 다시 하기 10 / NPC 추가 대화 8
- **충전**: 100개 ₩3,900 · 300개 ₩9,900(인기) · 700개 ₩19,900
- **구독권**: 구독권 선물하기 ₩9,900 · 커플 구독권 ₩14,900 · 팀 구독권 5인↑ 1인 ₩6,900
- **보석 부족 진입**: 상단에 필요·보유·부족 3칸 표
- **결제**: 현재 테스트 결제(즉시 반영). PG 연결 필요

### 20 프로필 (`profile`)
- 프로필 사진(카메라 버튼으로 실사 업로드) · 이름 · 플랜 · 연속/경험치/보석 · 내 코스 · 보유 아이템 · 계정
- **계정**: 연결된 계정 · 처리방침 · 로그아웃 · 기록 모두 지우기
- **삭제 확인**: "사진, 기록, 대화, 경험치와 보석이 모두 지워져요. 되돌릴 수 없어요."
- **사진 없음**: 이름 첫 글자 + 이름별로 다른 파스텔 배경

### 21 랭킹 (`rank`)
- LV(완료 미션 수) 1순위, 경험치 2순위. 내 행은 빨간 테두리로 강조
- 프로필 사진 또는 이름 첫 글자

## 전역 규칙

**키보드** — Enter: 다음/전송/제출 · ↑↓: 선택지 이동 · 입력창 포커스 중에는 화면 단축키 무시

**보상 표기** — 미리보기는 범위(`+100~140 XP`), 결과는 확정값. 항상 `+` 를 붙인다

**문구 톤** — 해요체. 실패를 사용자 잘못으로 돌리지 않는다. 부족한 점은 다음 연습 제안으로 바꿔 말한다. 점수와 숫자는 사용자에게 보여주지 않는다(보상 제외)

**하루 1미션** — 무료는 코스 합산 하루 1개. 자정에 초기화. Plus는 무제한. Tweaks `dailyLimit`로 끌 수 있다

**빈 상태·실패** — 사진 실패 / LLM 실패 / 복귀 / 스트릭 끊김 / 네트워크(임시 저장) / 기록 없음 / 코스 완료 — 7가지 모두 정의됨

**미구현** — 실제 결제, Google OAuth, Vision 호출, 공유 링크 서버, 사진 스토리지 업로드
