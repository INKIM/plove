# PLOVE LLM 비용 계산

작성 2026-09-19 · 실제 호출 지점과 프롬프트 길이를 세어 계산했다.

## 호출 지점 4곳

| 지점 | 입력 (추정) | 출력 (max) | 빈도 |
|---|---|---|---|
| 회고 질문 (`askNpc`) | 약 500토큰 (미션 + 목표 + 과제 + 기록 + 대화 누적) | 200 | 미션당 2~5회 |
| 미션 채점 (`gradeMission`) | 약 800토큰 (기록 + 대화 전문 + 사전 판정) | 400 | 미션당 1회 |
| 테스트 결과 (`readTest`) | 약 900토큰 (15문항 응답) | 500 | 계정당 코스별 1회 |
| 코스 편지 (`writeLetter`) | 약 1,200토큰 (29개 기록 발췌) | 500 | 코스당 1회 |

한글은 토큰이 영문의 약 1.5배라 위 숫자에 이미 반영했다.

## 미션 1건 비용

회고 대화는 소요시간에 따라 2~5턴이다. 평균 3턴으로 잡으면:

- 질문 3회 → 입력 1,500 / 출력 600
- 채점 1회 → 입력 800 / 출력 400
- **합계: 입력 2,300 / 출력 1,000 토큰**

모델별 단가 (100만 토큰당, 2026년 9월 기준 공개가):

| 모델 | 입력 | 출력 | 미션 1건 | 월 30건 |
|---|---|---|---|---|
| Haiku 4.5 | $1 | $5 | $0.0073 | **$0.22 (약 300원)** |
| Sonnet 4.5 | $3 | $15 | $0.0219 | **$0.66 (약 900원)** |
| Opus 4.1 | $15 | $75 | $0.1095 | **$3.29 (약 4,500원)** |

환율 1,370원 기준.

## 구독가 대비 원가

Plus 월 9,900원 (부가세 포함 → 실수령 약 9,000원). 매일 1미션을 하는 구독자 기준:

| 모델 | 월 원가 | 원가 비중 | 남는 돈 |
|---|---|---|---|
| Haiku 4.5 전부 | 300원 | **3.3%** | 8,700원 |
| Sonnet 4.5 전부 | 900원 | **10%** | 8,100원 |
| 혼합 (질문 Haiku + 채점 Sonnet) | 490원 | **5.4%** | 8,510원 |
| Opus 4.1 전부 | 4,500원 | **50%** | 4,500원 |

여기에 테스트 결과(1회)와 코스 편지(코스당 1회)를 더해도 미션 비용의 3% 이내다.

무료 사용자는 하루 1미션이라 같은 계산이 그대로 적용된다 — **무료 사용자 1인당 월 300~900원이 나간다.** 이게 무료 정책의 실제 비용이다.

## 권고: 혼합

**질문 생성은 Haiku, 채점은 Sonnet.**

질문은 "한 번에 하나만, 두 문장 이내"라는 단순한 형식 작업이라 Haiku로 충분하다. 채점은 성실·불성실을 가려야 하고 점수가 흔들리면 안 되므로 상위 모델이 낫다. 이 조합이 월 490원, 원가 5.4%다.

Opus는 쓸 이유가 없다 — 원가가 구독료의 절반이 된다.

## Vision을 붙이면 (9번 항목)

사진 1장은 크기에 따라 약 1,000~1,600토큰이다. 미션당 사진이 1~3장이니 평균 2장으로 보면 입력 3,000토큰이 추가된다.

| 모델 | Vision 추가분 (월 30건) | 합계 |
|---|---|---|
| Haiku 4.5 | +120원 | 420원 |
| Sonnet 4.5 | +370원 | 1,270원 |

**절감안**: 사진을 1024px 이하로 리사이즈해서 보내면 토큰이 절반 이하로 줄고 판정 정확도는 거의 같다. 업로드 시점에 캔버스로 줄여서 저장하면 스토리지 비용도 함께 줄어든다.

## 추가 절감안

1. **질문 캐싱** — 미션별 첫 질문은 기록에 거의 무관하다. 미션당 3~5개를 미리 만들어 두고 돌려쓰면 첫 질문 호출이 사라진다 (미션당 1콜 절감 = 25%)
2. **채점 입력 줄이기** — 대화 전문 대신 사용자 발언만 보내면 입력이 40% 줄어든다
3. **턴 수 하향** — 지금 평균 3턴이다. 2턴으로 줄이면 미션당 25% 절감. 다만 검증 품질이 떨어진다
4. **보석 아이템이 상한을 만든다** — "추가 대화"는 보석 8개를 받으므로 헤비 유저의 호출이 수익과 함께 늘어난다. 지금 구조가 이미 방어적이다

## 결제 (미구현)

현재는 테스트 결제로 즉시 반영된다. 실제 붙일 상품:

| 상품 | 가격 |
|---|---|
| PLOVE Plus | 월 9,900원 |
| 커플 구독권 | 월 14,900원 |
| 팀 구독권 | 1인 월 6,900원 (5인 이상) |
| 구독권 선물 | 9,900원 (1개월) |
| 보석 100개 | 3,900원 |
| 보석 300개 | 9,900원 |
| 보석 700개 | 19,900원 |

국내 서비스라 PG는 토스페이먼츠·포트원 중에서 고르면 된다. 구독은 정기결제(빌링키) 지원이 필요하고, 보석은 단건 결제다. 앱으로 낼 계획이 있으면 인앱 결제 수수료(30%)를 감안해 가격을 다시 봐야 한다 — 그 경우 Plus의 실수령이 6,900원으로 떨어져 원가 비중이 7%가 된다.

## 숫자 확인이 필요한 것

위 단가는 공개가 기준이다. 실제 계약 단가나 쓰려는 모델이 다르면 알려달라 — 표를 다시 계산한다. 토큰 수도 실제 호출 로그로 재보면 더 정확해진다 (지금은 프롬프트 길이 기준 추정).
